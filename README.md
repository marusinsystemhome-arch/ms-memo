# MSメモ

モーニングセミナー（MS）・基礎講座など、倫理法人会の各種講座の内容を記録する、
自分専用のメモアプリです。ホーム画面に追加すると、独自アイコン付きのWebアプリ
として使えます。

## 公開URL（GitHub Pages）

https://marusinsystemhome-arch.github.io/ms-memo/

GitHub リポジトリ: https://github.com/marusinsystemhome-arch/ms-memo

独自ドメインでホストしているため、PC・iPhone・Android すべてで正しい
アイコン・アプリ名（MSメモ）でホーム画面に追加でき、PCのChrome/Edgeでも
自動インストールできます。

**自分専用のアプリのため、ログインもPIN入力も不要です。** 開くとすぐに
これまでの記録が読み込まれ、入力すると約1.5秒後に自動でGoogle ドライブへ
保存されます。保存・読み込みは、管理者(marusinsystem.home@gmail.com) 名義で
動く Google Apps Script のWebアプリを経由して行われます。

過去の内容はGoogleドライブの自動リビジョン機能で保持され、アプリ内の
「変更履歴」から見返せます。

## できること

- 1件のメモごとに以下を記録
  - 日付（曜日を自動表示）
  - 講座区分（MS／基礎講座／研修会・講習会／全国講演会／会長例会／その他〈自由入力〉）
  - 講師名・テーマ
  - メモ欄:
    - 録音ファイル（iPhoneの録音機能などで録ったものをアップロードし、
      アプリ内でそのまま再生可能）
    - AIで要約した内容（ChatGPT/Claudeなどで要約した文章を貼り付ける欄）
    - フリーメモ（自由記述）
  - 画像（板書・スライドの写真など、1件につき最大6枚。アップロード時に
    自動で縮小されるので通信量を抑えられる）
- 「＋ 新しいメモを追加」でメモを何件でも追加可能。過去のメモも一覧から
  タップして開き、編集・削除できる
- 入力から約1.5秒後に自動でGoogle ドライブへ保存・次回開いたとき自動読み込み
- 「変更履歴」から過去に保存した内容をいつでも見返せる（Google ドライブの
  リビジョン機能）
- ホーム画面に追加すると、PC/iPhone/Android共通の専用アイコンで使える

## しくみ（Google Apps Script バックエンド、認証なし）

```
[自分のブラウザ] ── fetch ──▶ [Apps Script Webアプリ] ── Drive API ──▶ [管理者のGoogle Drive]
```

- Apps Scriptは管理者(marusinsystem.home@gmail.com)のアカウントで作成・
  デプロイされており、「次のユーザーとして実行: 自分」「アクセスできる
  ユーザー: 全員」の設定で動いている。そのため呼び出す側はGoogleログイン
  不要で、実行主体は常に管理者アカウント。
- 自分専用のアプリという前提のため、PINなどのアクセス制御は行っていない。
  Web App のURL（推測困難な長い文字列）を知っていれば誰でもデータを
  読み書きできる状態になる点はトレードオフとして許容している。
- ソース: `apps-script/Code.gs`（[デプロイ手順](apps-script/README.md)も同フォルダ）
- デプロイ済みURL: `index.html` の `APPS_SCRIPT_URL` に設定済み
  （値はこのREADMEには書かない。変更したくなったら `apps-script/README.md`
  の手順で再デプロイする）

### トレードオフ

- Web App URLを知っている人は誰でもデータを読み書きできる（自分専用・
  他人と共有しない前提なので実用上は許容している）
- 録音ファイルは大きいとアップロードに失敗しやすいため、目安として
  15MB程度までを推奨（超える場合は確認ダイアログが出る）
- 添付ファイル（録音・画像）を削除しても、Googleドライブ上の実ファイル
  自体は残る（記録からの参照だけが外れる、シンプルな設計のトレードオフ）

## データ・添付ファイルの保存先（Google ドライブ）

- 記録データ本体: `MSメモ_データ.json`（管理者アカウントのマイドライブ直下）
  保存のたびに同じファイルが上書き更新される。過去の内容はGoogleドライブの
  自動リビジョン機能で保持される。
- 録音ファイル・画像: `MSメモ_添付ファイル` フォルダ（管理者アカウントの
  マイドライブ直下、初回アップロード時に自動作成）。共有設定は変更せず
  非公開のまま。表示・再生・ダウンロードはすべてApps Script経由で行われる。

## 更新のしかた

このリポジトリ自体がGitHub Pages公開中のソース。編集後は次の手順で反映する。

```bash
git add -A
git commit -m "変更内容"
git push
```

push後、GitHub Pagesの再ビルドに数分かかる。複数のセッション・端末から
同時に編集することがあるため、pushで `fetch first` と弾かれた場合は
`git fetch && git log --oneline --all --graph` で何が起きているか確認して
からマージすること。

Apps Script側（`apps-script/Code.gs`）を編集した場合は、git push
だけでは反映されない。https://script.google.com/ でスクリプトを開き直し、
同じ内容に貼り替えてから「デプロイ」→「デプロイを管理」→ 既存デプロイの
編集（鉛筆アイコン）→ 新しいバージョンでデプロイし直す必要がある
（URLは変わらない）。

```
├── README.md                このファイル
├── index.html                アプリ本体
├── manifest.json             Web App Manifest
├── sw.js                     簡易Service Worker（インストール要件用。オフラインキャッシュ用途ではない）

│   ├── Code.gs
│   └── README.md             デプロイ手順
└── icon-src/                 アイコン生成に使ったスクリプトと元画像（ソースロゴが無いため、朝焼け＋メモ帳＋マイクのオリジナルデザイン）

    ├── resize-icons.ps1      マスター画像から各サイズを書き出すスクリプト
    └── icon-logo-master.png  マスター画像（1200×1200）
```
