# Apps Script バックエンド（個人利用・認証なし）

`Code.gs` は Google Apps Script にコピー&ペーストして使う。管理者
(marusinsystem.home@gmail.com) のGoogleアカウントで作成すること。

このアプリは自分専用で、他の人と共有しない前提のため、PINなどの
アクセス制御は行っていない。Web App のURLさえ知っていれば誰でも
データを読み書きできる状態になる点に注意（URL自体は推測困難な
長い文字列だが、漏らさないようにすること）。

## デプロイ手順

1. https://script.google.com/ を開く（marusinsystem.home@gmail.com でログイン）
2. 「新しいプロジェクト」
3. プロジェクト名を適当に変更（例: 「MSメモ バックエンド」）
4. エディタに最初から入っている `myFunction` などのコードを全部消し、
   このフォルダの `Code.gs` の中身を丸ごと貼り付ける
5. 右上「デプロイ」→「新しいデプロイ」
   - 種類の選択（歯車アイコン）→「ウェブアプリ」
   - 説明: 何でもよい
   - 次のユーザーとして実行: **自分（Me）**
   - アクセスできるユーザー: **全員**
     （Googleログイン画面を出さないための設定。コード側にPINチェックが
     無いため、実質的にはURLを知っている人だけがアクセスできる状態）
   - 「デプロイ」
6. 初回は権限確認画面が出る（自分のアカウントなので許可するだけ）
7. 発行された「ウェブアプリ」のURL（`https://script.google.com/macros/s/.../exec`
   の形）をコピーして、`site/index.html` の `APPS_SCRIPT_URL` に設定する

## データと添付ファイルの保存先

- 記録データ本体: 管理者のマイドライブ直下に `MSメモ_データ.json` として保存
- 録音ファイル・画像: 管理者のマイドライブに自動作成される `MSメモ_添付ファイル`
  フォルダの中に保存される。共有設定は変更しない（非公開のまま）。
  アプリからの表示・再生・ダウンロードは、すべてこのApps Script経由
  （`?action=file&id=...`）で行われる。

## Code.gsを更新した場合

`git push` だけでは反映されない。https://script.google.com/ でスクリプトを
開き直し、同じ内容に貼り替えてから「デプロイ」→「デプロイを管理」→
既存デプロイの編集（鉛筆アイコン）→ 新しいバージョンでデプロイし直す
必要がある（URLは変わらない）。

## 動作確認

デプロイ後、以下のようなcurlコマンドでも直接テストできる（`<URL>`は
実際の値に置き換える）:

```bash
curl -X POST "<URL>" -H "Content-Type: text/plain" \
  -d '{"action":"load"}'
```

`{"ok":true,"exists":false}` のような応答が返れば正常（まだ保存データがない状態）。
